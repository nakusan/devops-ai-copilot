# 6.8 大文件分析模块 Analysis Worker（Python）

> 所属系统：DevOps AI Copilot — 智能面（Python AI Plane）  
> 模块定位：**大日志/Heap 文件的异步离线分析** — 消费 Kafka，简化解析，回调 Java 更新 `analysis_jobs`  
> 参考业界：Eclipse MAT（生产级）、简化版关键字提取（MVP）、ELK Ingest Pipeline

---

## 1. 功能背景与边界

### 1.1 功能背景

场景二：用户上传 50MB~100MB 的 Heap Dump、GC 日志或超大 app.log，不能阻塞 Web 线程，也不能在对话中同步解析。

本模块与 6.4 Ingest Worker **共用 Kafka + MinIO 基础设施**，但 **业务目标不同**：

| 对比 | 6.4 Knowledge Ingest | 6.8 Analysis Worker |
|------|----------------------|---------------------|
| Topic | `knowledge.ingest.v1` | `analysis.ingest.v1` |
| 目标 | 切块 + 向量化 → RAG | 特征提取 → 诊断摘要 |
| 产出 | `knowledge_chunks` | `analysis_jobs.result_summary` |
| 聊天引用 | RAG RetrieveNode | LangGraph `analysis` 意图 |

### 1.2 模块职责（In Scope）

| 能力 | 说明 |
|------|------|
| Kafka Consumer | 消费 `analysis.ingest.v1` |
| MinIO 下载 | 流式读源文件 |
| MVP 简化解析 | 前 1MB 文本 + 关键字/模式统计 |
| 结果写入 | `result_summary` + 可选 `result_object_key`（JSON 详情） |
| 状态回调 | PATCH Java `/internal/v1/analysis-jobs/{id}` |
| 幂等 | 以 `jobId` 去重 |

### 1.3 模块边界（Out of Scope）

| 不属于本模块 | 归属 |
|--------------|------|
| 文件上传、Kafka 生产 | 6.3 Java |
| 完整 MAT 级 Heap 分析 | V2 |
| 聊天 SSE | 6.2 |
| Router 意图判定 | 6.5 |

## 4. MVP 解析器逻辑

```python
KEYWORDS = {
    "OOM": r"OutOfMemoryError|java\.lang\.OutOfMemoryError",
    "FULL_GC": r"Full GC|Pause Full",
    "EXCEPTION": r"Exception|ERROR",
}

def analyze_text_sample(text: str, file_type: str) -> dict:
    counts = {k: len(re.findall(p, text)) for k, p in KEYWORDS.items()}
    top_exceptions = re.findall(r"([a-zA-Z0-9_.]+Exception)", text)[:5]
    return {
        "file_type": file_type,
        "sample_bytes": len(text),
        "keyword_counts": counts,
        "top_exceptions": list(dict.fromkeys(top_exceptions)),
    }

def build_summary(parsed: dict) -> str:
    c = parsed["keyword_counts"]
    return (
        f"文件类型: {parsed['file_type']}。\n"
        f"采样分析（前 {parsed['sample_bytes']} 字节）：\n"
        f"- OOM 相关: {c['OOM']} 处\n"
        f"- Full GC: {c['FULL_GC']} 处\n"
        f"- Exception/ERROR: {c['EXCEPTION']} 处\n"
        f"- 常见异常: {', '.join(parsed['top_exceptions']) or '无'}"
    )
```

**限制**：`.hprof` 二进制文件 MVP 仅尝试文本化采样；解析质量有限，验收以降低门槛为准。
